# AstroDeck glossary

**Accessible name**. The name assistive technology uses to identify a control. It may come from visible text, image alt text or an explicit label and should describe the control's destination or action.

**Build output**. Files produced by a production build and prepared for deployment.

**Clean starter**. The project after demo cleanup. It contains a minimal home page and a 404 page, with an optional blog.

**Decorative image**. An image that adds no information or function to the surrounding content. Use an empty alt attribute for it.

**Fragment link**. A link to a named location within a document.

**Image-only link**. A link whose visible content consists of images. Its accessible name describes the destination or action.

**Production origin**. The scheme, host and port of the site's production URL.

**Role fallback list**. An ordered list of accessibility roles. A browser uses the first role it recognizes.

**Sitemap**. A file listing page URLs for search engines to discover.

**Sitemap index**. A file listing the locations of other sitemaps.
